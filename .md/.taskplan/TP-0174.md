- Corpo do avaliar validado no limite com o schema do contrato antes do envio (ids sem repetição e dentro dos aptos); o servidor revalida (422).
- Escrita pelo `escrever`: `X-Pelada: 1`, mesma origem, 401 → entrar; `grupoId` com `encodeURIComponent`.
- Composição só em memória (nada em `localStorage`/IndexedDB, G-17); apelidos só como texto React.
- Debounce + cancelamento limitam pedidos ao Worker (G-12). No diff: sem `style=`, CSS só com tokens, sem import de `@pelada/dominio` (G-01).
