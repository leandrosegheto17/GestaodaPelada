## 1. Plano de execução
**Reaproveitamento:** USAR `redefinirSenha(db, contaId, autor)` e `ContaNaoEncontrada` de `src/aplicacao/acesso/senhas.ts` (TP-0037) — gerar senha, encerrar sessões, resolver o pedido pendente (RF-06) e auditar ficam lá, nunca na rota; `SenhaExibida` de `backend/contrato/src/admins.ts` (TP-0021); `exigirVinculo` (TP-0032); `vinculos.buscar(db, grupoId, contaId)` (TP-0029) para "alvo é admin deste grupo"; `contas.buscarPorId` (traz `eDono`, TP-0027) já usado pela rota do dono (TP-0060); schema uuid de `contrato/base`; 404 e (se a TP-0064/0065 já criou) `responderErro` de `src/entrada/erros.ts`; `test/isolamento/casos.ts` (TP-0033).
**Camada:** `backend/api/src/entrada/rotas/grupos/admins/redefinir-senha.ts` → `entrada` (rota fina; a autorização é do chamador, conforme o cabeçalho de `senhas.ts`); registro em `src/entrada/app.ts`.
**Referência visual:** não se aplica (forma: `.md/mockup/respostas/senha-redefinida.json`).

1. TDD primeiro (Seção 2).
2. `POST /api/grupos/:grupoId/admins/:contaId/redefinir-senha`: `:contaId` uuid antes do banco (malformado → 404 sem consulta) → `contaId === c.var.sessao.conta.id` → recusa (status no PENDENTE) → `vinculos.buscar(db, grupoId, contaId)` null → 404 `nao_encontrado` (alvo de outro grupo é indistinguível de inexistente) → alvo com `eDono` → 404 (ADR-013: a senha do dono só muda pelo `dono.ts`) → `redefinirSenha(db, contaId, { tipo: 'conta', contaId: autor })` (`ContaNaoEncontrada` em corrida → 404) → 200 com `SenhaExibida.parse(...)`, `Cache-Control: no-store` conferido.
3. DECIDIDO (Coordenador): 409 `acao_na_propria_conta` ("Use Minha senha para trocar a sua."), com arquivo/schema no `contrato/admins`. Pergunta original: status/código da própria conta. A UX (T19) não oferece o botão na própria linha; o aceite só diz "nunca". Proposta: 409 com o mesmo código que a TP-0065 usar para "a si mesmo" (sugestão genérica `acao_na_propria_conta`, "Use Minha senha para trocar a sua."), com arquivo de resposta/schema no contrato. Alternativa: 404. Confirmar.
4. `casos.ts`: `"POST /api/grupos/:grupoId/admins/:contaId/redefinir-senha"` → `tipo: 'grupo'`, `parametros` com um admin real do grupo A (o helper prova que a senha dele não mudou). Reler `app.ts`/`casos.ts` antes de editar.
Não fazer: chamar repositórios de contas/sessões/pedidos para redefinir; logar a senha.
