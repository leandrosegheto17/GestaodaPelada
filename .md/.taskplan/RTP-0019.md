## 1. Plano de execução
Origem: DevSecOps da TP-0016 (média). `funcaoDe` só reconhece declaração de função, arrow/function expression direta e `export default` arrow/function. Sonda executada: arquivo com `export const f = envolver((id) => id)`, `export const o = { listar(id) {} }` e `export class R { listar(id) {} }` sai com código 0. O guarda de isolamento (G-03) fica contornável por padrão de escrita.
1. Em `funcaoDe`/laço de exports: para variável cujo inicializador é chamada, objeto literal ou classe, ou falhar fechado ("forma de export não analisável; use função declarada ou exceção com motivo"), ou descer nos membros/argumentos-função. Preferir falhar fechado (mais simples).
2. Testes em `test/banco.test.mjs` para os três casos.
