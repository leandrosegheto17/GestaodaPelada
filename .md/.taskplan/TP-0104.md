## 1. Plano de execução
**Reaproveitamento:** USAR `Faixa` de `ui/basicos` (TP-0095; variação `atencao`, `topo`, `role=status`, sem botão de fechar) — UX-SPEC §7 diz que não é componente visual novo; e `useLocation` do React Router (TP-0088). O campo `enderecoNovo` vem pronto de `GET /api/sessao/eu` e do ranking público (ADR-010; tipos de `contrato/sessao` e `contrato/publico`). Nada a extrair.
**Camada:** `@pelada/web` → `frontend/web/src/componentes/aviso-endereco-novo/`: `AvisoEnderecoNovo.tsx`, `linkEnderecoNovo.ts` (função pura), `index.ts`. Sem CSS próprio (classes da `Faixa`).
**Referência visual:** `.md/mockup/telas/t01-ranking--endereco-novo.html` linha 21 e `t09-inicio--endereco-novo.html` linha 15: `div.faixa.faixa--atencao.faixa--topo[role=status]` > SVG de alerta (`.icone`, `aria-hidden`) + `p.faixa__texto` > `strong` "O app mudou de endereço." + `a` "Abrir o novo endereço e reinstalar"; `.md/mockup/base.css` linhas 68–77. Comparação visual pelas telas que o usam: `pnpm --filter @pelada/web visual --tela T01` (estado endereco-novo, TP-0111) e `--tela T09` (estado endereco-novo, TP-0119).

1. TDD: testes da seção 2 primeiro.
2. `linkEnderecoNovo(enderecoNovo, rota)`: `rota` = `pathname + search + hash` da tela atual; resultado = `new URL(rota, enderecoNovo).href` (mantém a mesma rota no host novo, ADR-010). Devolve `null` se `enderecoNovo` for nulo/vazio, não for URL válida ou o protocolo não for `https:` (falha fechado: sem faixa, sem link).
3. `AvisoEnderecoNovo({ enderecoNovo })`: `null` → não renderiza nada; senão `Faixa` de atenção no topo, **sem** fechar, com o texto e o link do mockup (`<a href={link}>`, mesma aba). A tela decide onde colocá-la (logo abaixo da barra, T01/T09).
4. A URL absoluta só existe em tempo de execução, vinda da API (G-18): nenhum host escrito no código.

NÃO fazer: lógica do service worker ao receber `enderecoNovo` (ADR-010, tarefa do PWA, TP-0108); guardar "fechado".

## 2. Plano de teste

- axe sem violação.
- Comando: `pnpm --filter @pelada/web test -- src/componentes/aviso-endereco-novo`.

## 3. Plano de validação de segurança
- Redirecionamento aberto / XSS por `href`: o link só é montado com `https:` e sempre no host de `enderecoNovo` (matriz acima); a rota anexada é a do próprio app. Conferir no diff que não há `dangerouslySetInnerHTML` nem `window.location` atribuído automaticamente (o usuário escolhe tocar no link).
- G-18: nenhuma URL absoluta no código; o valor vem de `ENDERECO_NOVO` no servidor (ADR-010). G-01, G-19, G-23.
