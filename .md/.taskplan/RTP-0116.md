# RTP-0116 — Teste de ícones PWA falha: public/icones diferem do mockup byte a byte

Reserva: Livre
ID no TASK.md: RTP-0116 · Lote: Refatoração Lote-L23 · Agente: executor · Chapéu: Frontend · Est: 0,25 d · Dep: TP-0108 · Status no TASK.md: Pendente
Reqs: TP-0108; ADR-009 · Aceite: `npx vitest run test/pwa-config` passa por inteiro; `public/icones` batem com `.md/mockup/icones` (ou, se o mockup é que mudou, o artefato correto é atualizado de forma consciente).

## 1. Plano de execução
Origem: QA da RTP-0107 (preexistente, introduzido no TP-0108; não causado pela RTP-0107). `test/pwa-config.test.ts` "os arquivos de ícone são os do mockup, byte a byte" falha. Descobrir qual arquivo difere, decidir qual lado é a fonte da verdade e alinhar.

## 2. Plano de teste
`cd frontend/web && npx vitest run test/pwa-config`.

## 3. Plano de validação de segurança
Não se aplica.

## Bloqueio
Diagnóstico: os 4 PNGs de `frontend/web/public/icones` (apple-touch-180, icone-192, icone-512, icone-512-maskable) diferem de `.md/mockup/icones`. A cópia em `public/icones` veio do TP-0108 (commit 655c19c3, 2026-10-16), anterior à aprovação do ícone pelo usuário (f0aa41ec) e à restauração dos PNG aprovados no mockup (4068f6ae, 2026-10-17). A fonte da verdade é o mockup (aprovado). Correção: copiar os 4 PNGs do mockup sobre `public/icones`. O sobrescrever binário foi negado pelo classificador de permissões; precisa de autorização do usuário (ou rodar `cp .md/mockup/icones/{apple-touch-180,icone-192,icone-512,icone-512-maskable}.png frontend/web/public/icones/`) e depois `cd frontend/web && npx vitest run test/pwa-config`.
