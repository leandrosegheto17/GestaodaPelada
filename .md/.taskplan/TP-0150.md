## 1. Plano de execução
**Reaproveitamento:** USAR `saidaNoIntervalo` e o tipo `AptoOrdenado` de `backend/dominio/src/simulador/classificacao.ts` (TP-0149) — quem sai é derivado só ali. EXTRAIR de `backend/dominio/src/elenco/nivel.ts` (TP-0011) a divisão inteira meio-para-cima (`Math.floor((200*s + n)/(2*n))`) para uma função exportada `dividirMeioParaCima(numerador, denominador)` no mesmo arquivo; `calcularNivel` passa a chamá-la (`dividirMeioParaCima(100*s, n)`) e as médias daqui também. Este módulo é a única fonte de indicadores e pares: TP-0151/0152 (busca), TP-0153 (avisos), TP-0154 (`sugerir`) e TP-0166 (`avaliar`) o usam.
**Camada:** `@pelada/dominio`, `backend/dominio/src/simulador/tipos.ts` e `backend/dominio/src/simulador/indicadores.ts` (SDD §2, `src/simulador`). Regra pura, inteiros (ADR-007 §4).
**Referência visual:** não se aplica (forma de saída em `.md/mockup/respostas/simulador-sugestao-dois.json` e `-varios.json`; o adaptador divide por 100).

1. `tipos.ts`: `JogadorSim extends AptoOrdenado { nivel: number /* × 100 */; idade: number; semNota: boolean }`; `ComposicaoDois { times: [TimeDois, TimeDois]; naoEntra: string[] }` com `TimeDois { titulares: string[]; entram: string[] }`; `ComposicaoVarios { times: { jogadores: string[] }[] }`. Tipos próprios (G-01, sem contrato).
2. `indicadoresDois(comp, jogadores: Map<id, JogadorSim>, rank: Map<id, number>)` por time: ordena titulares e entram por `rank`; `sai = saidaNoIntervalo(titulares, entram.length)`; `pares = zip(sai, entram)` (sai: só 1º tempo, depois do pior para o melhor; entram do melhor para o pior — confere com o arquivo: Pedrão → Cabeça, Rafinha → Japa; Juninho → Vini, Alemão → Léo Baiano); `substituicoes = pares.length`; `nivelSoma1/2`, `nivelMedio1/2` (2º tempo = titulares que ficam + entram; média `null` se ninguém), `idadeMedia` × 100, `jogadores1/2`. Sai/entra sem par (ajuste manual) ficam em `saiSemPar`/`entraSemPar` para os avisos.
3. `indicadoresVarios(comp, jogadores)` por time: `jogadores`, `nivelSoma`, `nivelMedio` × 100, `idadeMedia` × 100.
4. Incremental (ADR-014 §5 (a)): `Agregado { n, somaNivel, somaIdade }` com `agregar(ids)` e `trocarNoAgregado(agA, agB, sai, entra)` O(1) sem alocar arrays; para o 2º tempo, `somaNivel2oTempo(titularesOrdenados, entramQtd)` reaproveita `saidaNoIntervalo` só nos 2 times tocados. Função `chaveDois`/`chaveVarios` fica nas tarefas de distribuição; aqui só os agregados.
5. Export pelo ponto de entrada do pacote (reler antes; TP-0151/0152/0153 editam em paralelo; só as linhas novas). TDD: tabela primeiro.

DECIDIDO (Coordenador): titulares + entram (todos que jogam pelo time). Pergunta original: no formato 2 times, a "idade média" (RF-45, RN-10A item 4) é de quem joga no time (titulares + entram) ou só dos titulares do 1º tempo? Proposta: titulares + entram (todos que jogam pelo time).

Não fazer: arredondar com float; recalcular nível/idade (chegam prontos, TP-0164); gerar texto; regra de goleiro (P-13).
