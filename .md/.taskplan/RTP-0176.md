1. A partir de 2026-10-22 (ou após refresh do lockfile), trocar para `minimumReleaseAge: 10080`.
2. Rodar `pnpm install --frozen-lockfile`. Se ainda falhar, listar as versões recentes acusadas e decidir entre refresh do lockfile ou adiar; não usar lista longa de `minimumReleaseAgeExclude`.
3. Reavaliar se as 4 entradas de `trustPolicyExclude` ainda são necessárias.

**Reaproveitamento:** nenhum código novo; só o valor de uma chave já existente em `pnpm-workspace.yaml`.
