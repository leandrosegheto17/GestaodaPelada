## 3. Plano de validação de segurança
- Entrada validada pelo schema do contrato antes do envio (descrição 1 a 80, valor inteiro positivo dentro do limite, data `AAAA-MM-DD`, tipo do enum; CONVENCOES §8); a API revalida — o cliente não é a defesa.
- Escritas por `escrever` (`X-Pelada: 1`, G-09), sem retry automático; exclusão atrás do D2. `:id` validado e codificado antes de compor a URL; autorização é da API (`exigirFinanceiro` 403, isolamento 404, G-03).
- Descrição exibida como texto (sem HTML); nada guardado no aparelho (G-17); 401 → `/entrar?destino=`.
