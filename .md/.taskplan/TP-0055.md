1. TDD: testes de rota primeiro.
2. `metadados-grupo.ts`: `paraMetadadosGrupo(grupo)` → `{id, nome, diaSemana, frequencia, horario, situacaoComercial, inicioTrial, criadoEm, arquivadoEm}` com datas `AAAA-MM-DD` de São Paulo (se o repositório já entrega string de data, só seleciona campos; se entrega instante, converter aqui uma vez com `Intl` em `America/Sao_Paulo`, ADR-012). `urlPublicaDoGrupo(urlPublica, slug)` = `${urlPublica}/g/${slug}` — único lugar que monta o link (ADR-010, G-18).
