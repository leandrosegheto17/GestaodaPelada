# RTP-0026 — Pagina.module.css: regra @media de .conteudoEstreito anulada pela regra base

Reqs: UX-SPEC T08; CONVENCOES-DE-CODIGO · Aceite: em >=600px o padding lateral de `.conteudoEstreito` vale `--esp-6` de fato (regra base antes do `@media`, um único bloco `@media (min-width: 600px)`) e a comparação visual de T02/T03/T05/T08/T25 segue <=1%.

## 1. Plano de execução
Origem: QA da TP-0118. Em `frontend/web/src/componentes/pagina/Pagina.module.css` o `@media (min-width: 600px) { .conteudoEstreito { padding-left/right: var(--esp-6) } }` vem antes da regra base `.conteudoEstreito { padding-left/right: var(--esp-4) }` (mesma especificidade, a última vence), então o `@media` nunca vale; há também dois blocos `@media (min-width: 600px)` seguidos.
1. Mover a regra base de `.conteudoEstreito` para antes do `@media` e fundir os dois blocos `@media`.
2. Rodar a comparação visual de T02, T03, T05, T08 e T25; se divergir do mockup, manter o valor que o mockup pede (`base.css`).

## 2. Plano de teste
`npx vitest run src/componentes/pagina`; `visual --tela T02|T03|T05|T08|T25` ≤ 1%.

## 4. Resultado da execução
- Alterado: `frontend/web/src/componentes/pagina/Pagina.module.css` (regra base de `.conteudoEstreito` antes do `@media`; um único bloco `@media (min-width: 600px)`). Outra tarefa editou o mesmo arquivo em paralelo (`.conteudoPagina`) e preservou a correção.
