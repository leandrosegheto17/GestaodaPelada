# RTP-0113 — Alinhar o nome do branch de produção do Neon (`production`) em deploy.yml, SDD e tarefas seguintes

Reserva: Livre
ID no TASK.md: RTP-0113 · Lote: Refatoração Lote-L29 · Agente: executor · Chapéu: Backend · Est: 0,1 d · Dep: TP-0132
Reqs: SDD §3 PI-1; TP-0132; ADR-011 · Aceite: nenhuma referência ao branch de produção do **Neon** como `main` em `.github/workflows/deploy.yml`, `.md/SDD.md`, TP-0133 e TP-0135; todas usam `production` (ou o branch é renomeado para `main` no Neon e o `## 4` do TP-0132 é corrigido). A política de branch do environment no GitHub (TP-0134) continua `main`: é o branch do Git, não do Neon.

## 1. Plano de execução
Origem: QA do TP-0132 (não crítico). O projeto Neon real tem o branch padrão `production`, não `main`. Referências erradas: `deploy.yml` (`pai="main"` no passo "Branch de restauração no Neon": o `find` por nome falha e o passo sai com 1 em todo push), `SDD.md` linha 67 (tabela de ambientes) e PI-1, TP-0133 (isolamento "nunca para `main`") e TP-0135 passo 3 (`main` ou `teste`). Escolha mais barata: trocar o texto para `production`; alternativa: renomear o branch no Neon.

## 2. Plano de teste
`git grep -n -E "branch[^|]{0,30}main|pai=\"main\""` nos arquivos citados não devolve referência ao Neon; `deploy.yml` passa em `actionlint`/yaml e `pai` vale `production` quando AMBIENTE != teste.

## 3. Plano de validação de segurança
Não se aplica.
