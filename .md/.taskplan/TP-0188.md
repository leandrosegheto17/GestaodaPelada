## 1. Plano de execução
**Reaproveitamento:** USAR o runner `aplicarMigracoes` e a pasta `backend/api/src/infraestrutura/db/migracoes/` (TP-0015), `checar-migracao-aditiva.mjs` (TP-0016), o `globalSetup` de `backend/api/test/apoio/` (TP-0017), `test/apoio/sql.ts` (TP-0025), `TabelasBanco` em `infraestrutura/db/tipos.ts` (TP-0014), tabelas `grupos`/`contas` e `jogadores` com `UNIQUE (id, grupo_id)` (TP-0026/TP-0025/TP-0042). Tipo de lançamento igual à tupla de `backend/contrato/src/enums.ts`; faixas de `limites.ts` (TP-0005).
**Camada:** `backend/api/src/infraestrutura/db/migracoes/<AAAAMMDDHHMM>_financeiro.sql` e `infraestrutura/db/tipos.ts` → módulo de dados (G-02); teste `backend/api/test/migracoes/financeiro.test.ts`.
**Referência visual:** não se aplica.

1. Carimbo real do momento da implementação (SDD §6).
2. `config_financeira`: `grupo_id uuid PRIMARY KEY REFERENCES grupos` (1 por grupo), `mensalidade_centavos integer NULL CHECK (BETWEEN 1 AND 99999999)`, `saldo_inicial_centavos integer NOT NULL CHECK (BETWEEN -99999999 AND 99999999)`, `data_saldo_inicial date NOT NULL`.
3. `lancamentos`: `id uuid PK default gen_random_uuid()`, `grupo_id uuid NOT NULL REFERENCES grupos`, `UNIQUE (id, grupo_id)`, `tipo text NOT NULL CHECK IN ('entrada','saida')`, `data date NOT NULL`, `descricao text NOT NULL CHECK (char_length(btrim(descricao)) BETWEEN 1 AND 80)`, `valor_centavos integer NOT NULL CHECK (BETWEEN 1 AND 99999999)`, `criado_por`/`alterado_por uuid NOT NULL REFERENCES contas`, `criado_em`/`alterado_em timestamptz NOT NULL` (sem `now()`, G-06). Índice `(grupo_id, data)` (mês e soma do saldo).
4. `pagamentos_mes`: `grupo_id uuid NOT NULL`, `jogador_id uuid NOT NULL`, `mes text NOT NULL CHECK (mes ~ '^[0-9]{4}-(0[1-9]|1[0-2])$')` (ADR-012), `lancamento_id uuid NULL`, `marcado_por uuid NOT NULL REFERENCES contas`, `marcado_em timestamptz NOT NULL`; `PRIMARY KEY (jogador_id, mes)` (RN-15); `FOREIGN KEY (jogador_id, grupo_id) REFERENCES jogadores (id, grupo_id)` **sem cascade** (pagamento é histórico: bloqueia a exclusão do jogador, RF-22/L-10, igual à presença); `FOREIGN KEY (lancamento_id, grupo_id) REFERENCES lancamentos (id, grupo_id) ON DELETE RESTRICT` (barreira do 409 do TP-0198); `UNIQUE (lancamento_id)` (uma entrada por pagamento); índice `(grupo_id, mes)`.
5. Acrescentar as três tabelas em `TabelasBanco` (reler `tipos.ts` antes: outras tarefas o editam).

Atenção: o FK composto com `lancamento_id NULL` não é checado (MATCH SIMPLE), o que é o desejado. "Entrada vinculada é do tipo entrada" fica na aplicação (CHECK não cruza tabelas). Não fazer: repositório (TP-0189), coluna `numeric`/`money`, `ON DELETE CASCADE` de grupo.
