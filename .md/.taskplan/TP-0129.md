## 3. Plano de validação de segurança
- Autorização é da API (`exigirDono`, 404 para não dono, ADR-005/G-03); a guarda de `/dono` (TP-0105) só evita a tela vazia. Conferir que nenhum dado do painel é lido fora de `usePainelDono`.
- Senha exibida uma vez (ADR-004/ADR-015): a senha só vive no resultado da mutação e na prop do D1; `reset()` ao fechar; nada em `localStorage`/`sessionStorage`/IndexedDB/URL/log/`console`; o painel não é guardado pelo service worker (G-17: só `/api/publico/*/ranking*`).
- CSRF (G-09): as duas escritas passam por `escrever` (cabeçalho `X-Pelada: 1`); `contaId` vai na URL com `encodeURIComponent`.
- RF-07: a tela só desenha campos do `PainelDono` strict; nenhum atalho para dados internos.
- LGPD: e-mails dos admins só exibidos, nunca logados; texto sempre como texto (sem `dangerouslySetInnerHTML`).
