# TP-0012 — `dominio/slug`: link legível do grupo

Reserva: Livre
ID no TASK.md: TP-0012 · Lote: L02 · Agente: executor · Chapéu: Backend · Est: 0,5 d · Dep: TP-0001 · Status no TASK.md: Pendente
Reqs: ADR-016, RF-02 · Aceite: [PD] Slug do nome: minúsculas, sem acento, só `[a-z0-9-]`, hífens únicos, até 60; colisão com o conjunto de slugs já usados (inclusive arquivados) → sufixo `-2`, `-3`…; nome só com símbolos → `grupo`. Testes com acento, emoji, colisão em cadeia

## 1. Plano de execução
**Reaproveitamento:** nada a reaproveitar (Dep só TP-0001). O formato aceito pela rota pública (`slug [a-z0-9-]{1,64}`, Seção 1.4) é do `contrato/base` (TP-0005); o gerador daqui tem de produzir sempre algo dentro dele, mas não importa o contrato (G-01).
**Camada:** `@pelada/dominio`, pasta `backend/dominio/src/grupos/` (SDD §2, árvore: `grupos(slug)`; o artefato `dominio/slug` do TASK.md é o arquivo `grupos/slug.ts`).
**Referência visual:** não se aplica.

1. `grupos/slug.ts`: `slugBase(nome)` = `normalize('NFD')`, remove marcas combinantes (`\p{M}`), minúsculas, troca toda sequência fora de `[a-z0-9]` por um `-` (emoji, `ç` já decomposto, espaços, pontuação), tira `-` das pontas, corta no limite sem deixar `-` no fim; vazio → `grupo`.
2. `gerarSlug(nome, usados: ReadonlySet<string>)` = base; se em `usados`, tenta `base-2`, `base-3`… até livre (laço limitado a `usados.size + 2`). `usados` inclui slugs de grupos arquivados (ADR-016 §5) — quem monta o conjunto é o caso de uso de criação (TP-0047/repositório); a disputa concorrente é resolvida lá pelo índice único (ADR-016 §2), chamando de novo com o conjunto atualizado.
3. Cabeçalho do módulo: slug é imutável depois de gerado (ADR-016 §4; gatilho no banco é de outra tarefa).
4. Export pelo ponto de entrada do pacote (reler `index.ts` antes; só a linha nova).

DECIDIDO (Coordenador): o ADR-016 (Accepted) prevalece nos três pontos: (a) corte em 40; (b) fallback `grupo` também quando o resultado tem menos de 3 caracteres; (c) palavras reservadas recebem `-grupo`. Base + sufixo de colisão cabe nos 64 do contrato. O aceite deve ser lido conforme o ADR; a rota do TP-0056 testa o mesmo. Pergunta original: o aceite diverge do ADR-016 §1 e §3 (Accepted, decisão do usuário) em três pontos — qual vale? (a) corte em **60** (aceite) ou **40** (ADR); (b) fallback `grupo` só quando vazio (aceite) ou também quando o resultado tem **menos de 3** caracteres (ADR); (c) palavras reservadas `admin`, `api`, `dono`, `entrar`, `g`, `privacidade`, `conta`, `assets`, `well-known` recebendo o sufixo `-grupo` (ADR; ausente do aceite). Em qualquer escolha, base + sufixo de colisão precisa caber nos 64 do contrato.

Não fazer: consultar banco, gerar parte aleatória (rejeitada no ADR-016), mudar slug em renome.

## 2. Plano de teste
`backend/dominio/src/grupos/slug.test.ts`, tabela ([PD]):
- "Pelada de Quinta" → `pelada-de-quinta` (`publico-ranking-2026-10.json`); "Racha de Domingo" → `racha-de-domingo`; "Pelada do Leandro" → `pelada-do-leandro`.
- Acentos e cedilha: "Fúria São João Ação" → `furia-sao-joao-acao`; emoji e símbolos: "⚽ Pelada 🔥!!" → `pelada`; "  --Futebol__Amigos--  " → `futebol-amigos`; "Time 2026" mantém dígitos.
- Só símbolos/emoji "⚽🔥!!!" → `grupo`; colisão com `grupo` → `grupo-2`.
- Corte: nome de 60 caracteres cujo corte cairia num `-` não termina em `-` (limite conforme a decisão do PENDENTE).
- Colisão em cadeia: usados `{pelada, pelada-2, pelada-3}` → `pelada-4`; slug arquivado no conjunto também conta; conjunto vazio → base.
- Saída sempre casa `^[a-z0-9-]{1,64}$`, sem `--` e sem `-` nas pontas (propriedade em ~200 nomes gerados com acento, emoji e espaços).
- Se o PENDENTE (c) confirmar as reservadas: `"API"` → `api-grupo`, `"Admin"` → `admin-grupo`.
- Comando: `pnpm --filter @pelada/dominio exec vitest run src/grupos`; checagens da Seção 1.6 disponíveis.

## 3. Plano de validação de segurança
O slug vira caminho público (`/g/:slug`, `/api/publico/:slug`) e entra no PDF e no WhatsApp: a saída tem de ser estritamente `[a-z0-9-]` (sem `/`, `.`, `%`, `..`, caracteres Unicode de aparência igual — o NFD + filtro ASCII elimina homóglifos) e nunca colidir com rota do app (palavras reservadas, PENDENTE c). Matriz adversarial nos testes: string vazia, só espaços, só emoji, letras de outros alfabetos ("Пелада", "足球" → `grupo`), nome com `../`, `%2F`, caracteres de largura zero. Laço de colisão limitado (sem laço infinito com conjunto grande). Sem relógio (G-06), sem import externo (G-01), sem ID de tarefa (G-23). Enumeração por slug é risco aceito (T-13), fora do escopo.
