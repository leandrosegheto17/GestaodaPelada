# RTP-0172 — Ignorar no git o arquivo de entrada da importação do legado

Reserva: Livre
ID no TASK.md: RTP-0172 · Lote: Refatoração Segurança 2026-10-20 · Agente: executor · Chapéu: Backend · Dep: — · Status no TASK.md: Pendente
Reqs: ADR-021 item 5; RNF-06 · Aceite: padrão no .gitignore e git check-ignore confirma o nome esperado pelo script

## 1. Plano de execução
Origem: auditoria de segurança de release de 2026-10-20 (`.md/SECURITY-REVIEW.md`, entrada no topo). **Reaproveitamento:** o `.gitignore` existente.
1. Acrescentar ao `.gitignore` os padrões dos arquivos de entrada do script (`Cadastro.md`, `Pontuacoes.md` e o JSON de correções) fora de `.md/`, com comentário sobre dado pessoal.
2. Conferir com `git check-ignore -v`.

## 2. Plano de teste
`git check-ignore -v Cadastro.md Pontuacoes.md correcoes.json` casando.

## 3. Plano de validação de segurança
Evita commit acidental de dado pessoal (LGPD).

## 4. Resultado da execução
- `.gitignore`: `Cadastro.md`, `Pontuacoes.md`, `correcoes.json` e, por pedido do usuário, os brutos da auditoria (`.md/.seguranca/*/*.json` e `.md/.seguranca/*/dast-*/`, que incluem o `gitleaks.json` com JWTs de demonstração). `sondas.json`, `sondas-web.json` e `resumo-ferramentas.md` seguem versionados.
- `git check-ignore -v Cadastro.md Pontuacoes.md correcoes.json .md/.seguranca/2026-10-20/gitleaks.json .md/.seguranca/2026-10-20/dast-api`: todos casam; `sondas.json` não é ignorado.
- Arquivo alterado: `.gitignore`.
