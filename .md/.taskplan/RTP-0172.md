# RTP-0172 — Ignorar no git o arquivo de entrada da importação do legado

Reserva: Livre
Classe: seguranca-deploy
ID no TASK.md: RTP-0172 · Lote: Refatoração Segurança 2026-10-20 · Agente: executor · Chapéu: Backend · Dep: — · Status no TASK.md: Pendente
Reqs: ADR-021 item 5; RNF-06 · Aceite: padrão no .gitignore e git check-ignore confirma o nome esperado pelo script

## 1. Plano de execução
Origem: auditoria de segurança de release de 2026-10-20 (`.md/SECURITY-REVIEW.md`, entrada no topo). **Reaproveitamento:** o `.gitignore` existente.
1. Acrescentar ao `.gitignore` os padrões dos arquivos de entrada do script (`Cadastro.md`, `Pontuacoes.md` e o JSON de correções) fora de `.md/`, com comentário sobre dado pessoal.
2. Conferir com `git check-ignore -v`.

## 2. Plano de teste
`git check-ignore -v Cadastro.md Pontuacoes.md correcoes.json` casando.

## 3. Plano de validação de segurança
Evita commit acidental de dado pessoal (LGPD).

## 4. Resultado da execução
- `.gitignore`: `Cadastro.md`, `Pontuacoes.md`, `correcoes.json` e, por pedido do usuário, os brutos da auditoria (`.md/.seguranca/*/*.json` e `.md/.seguranca/*/dast-*/`, que incluem o `gitleaks.json` com JWTs de demonstração). `sondas.json`, `sondas-web.json` e `resumo-ferramentas.md` seguem versionados.
- `git check-ignore -v Cadastro.md Pontuacoes.md correcoes.json .md/.seguranca/2026-10-20/gitleaks.json .md/.seguranca/2026-10-20/dast-api`: todos casam; `sondas.json` não é ignorado.
- Arquivo alterado: `.gitignore`.


## 5. Resultado do QA
**Veredito: APROVADA.**

Testado (plano de teste da tarefa):
- `git check-ignore -v Cadastro.md Pontuacoes.md correcoes.json .md/.seguranca/2026-10-20/gitleaks.json .md/.seguranca/2026-10-20/dast-api/x`: os 5 casam (`.gitignore` linhas 26-30).
- Os versionados continuam rastreados: `git check-ignore` de `.md/.seguranca/sondas.json`, `sondas-web.json` e `2026-10-20/resumo-ferramentas.md` retorna rc=1 (não ignorados). O padrão `.md/.seguranca/*/*.json` só atinge o nível da data, não esses arquivos.
- `git ls-files` não lista nenhum `Cadastro.md`, `Pontuacoes.md`, `correcoes.json`, `gitleaks` nem `dast-*`: nenhum dado pessoal rastreado. Os brutos (`gitleaks.json`, `semgrep.json`, `osv-scanner.json`, `dast-*`) existem só no disco, ignorados.
- Diff: só `.gitignore` (+7 linhas), com comentário verdadeiro e sem ID de tarefa. Conforme CONVENCOES-DE-CODIGO; sem código.
- Nota: `importar-legado.ts` recebe os caminhos por `--cadastro`, `--rodadas` e `--correcoes`, sem nome fixo. Os padrões cobrem os nomes de convenção do aceite; um arquivo com outro nome não seria ignorado. Não reprova o aceite.

Achados: 0 críticos, 0 não críticos.
Resumo para o relatório: APROVADA; 0 críticos, 0 não críticos; git check-ignore casa as entradas e os brutos da auditoria, os versionados seguem rastreados e nenhum dado pessoal está no git.
