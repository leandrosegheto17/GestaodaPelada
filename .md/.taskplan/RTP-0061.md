Reqs: RTP-0057; G-03; SDD §6 · Aceite: `checar-grupo-id.mjs` sai ≠ 0 para export sem `grupoId` em: classe com propriedade (static ou de instância) arrow/function, classe com `extends`, `export let/var/declare const` sem inicializador, `export import X = ...`, re-export de módulo fora da pasta; teste por caso em `test/banco.test.mjs`; raiz real segue exit 0.

## 1. Plano de execução
Origem: DevSecOps da RTP-0057 (média). Sondas executadas, todas exit 0: `export class C { static f = (id: string) => id; }`; `export class C { constructor(public f = (id: string) => id) {} }`; `class B { m(id: string){} } export class C extends B {}`; `export let f: (id: string) => string; f = (id) => id;`; `export declare const f: (id: string) => string;`; `import b = require("./b"); export import X = b;`; `export { y } from "../outside"`. `formaNaoAnalisavel` só olha métodos/acessores da classe e devolve null quando não há inicializador.
1. Classe: não analisável se tiver `PropertyDeclaration` (ou parâmetro-propriedade) com inicializador callable/não literal, ou `heritageClauses` com extends.
2. Declaração sem inicializador (`let`/`var`/`declare const`) com tipo não literal: não analisável.
3. `ImportEqualsDeclaration` exportado e re-export cujo dono está fora da pasta: não analisável.
4. Um teste "falha" por sonda.

As sondas acima saem com código ≠ 0; dados literais e classes só com construtor continuam passando.

## 4. Resultado da execução
Feito: `formaNaoAnalisavel` virou LISTA DE PERMITIDOS (`declaracaoEhDado`): só passa sem análise o que for comprovadamente dado — const com literal/objeto só de literais, `let/var/declare` sem inicializador só com tipo primitivo/literal, enum literal, classe sem função como membro (propriedade só com inicializador literal ou tipo de dado; parâmetro-propriedade idem; sem bloco static) e única herança aceita `extends Error` do lib padrão. Qualquer outro nó (ImportEquals, destructuring, let/var com valor, classe com extends, export default de classe etc.) falha fechado. Re-export (`export {..} from`, `export *`, `export * as`) com módulo fora da pasta ou não resolvido falha (check por `resolveModuleName` + alias sem declaração); `export import` falha.
