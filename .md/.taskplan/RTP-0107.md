# RTP-0107 — sw.ts: validade máxima (maxAgeSeconds) no cache do ranking público

Reserva: Livre
ID no TASK.md: RTP-0107 · Lote: Refatoração Lote-L23 · Agente: executor · Chapéu: Frontend · Est: 0,25 d · Dep: TP-0108 · Status no TASK.md: Pendente
Reqs: ADR-009; ADR-016/T03; G-17; TP-0108 · Aceite: ExpirationPlugin do cache `ranking-publico` com `maxAgeSeconds` definido (ex.: 7 dias); teste de configuração confere; ranking de grupo arquivado não é servido offline depois do prazo

## 1. Plano de execução
Origem: DevSecOps da TP-0108 (baixa). `frontend/web/src/pwa/sw.ts` usa `new ExpirationPlugin({ maxEntries: 50 })` sem idade máxima: o ranking de um grupo depois arquivado/tornado privado continua servido do cache em falha de rede ou timeout de 3 s, indefinidamente.
1. Acrescentar `maxAgeSeconds` ao `ExpirationPlugin` (valor numa constante nomeada).
2. Cobrir em `test/pwa-config.test.ts` (ou teste do módulo de regras) que a idade máxima existe.

## 2. Plano de teste
`pnpm --filter @pelada/web test -- src/pwa test/pwa-config` e `pnpm --filter @pelada/web build`.

## 3. Plano de validação de segurança
G-17/ADR-009: cache do ranking com validade finita; nenhuma outra rota /api em cache.

## 4. Resultado da execução
Feito: constante `RANKING_VALIDADE_SEGUNDOS = 7 * 24 * 60 * 60` em `frontend/web/src/pwa/sw.ts`, usada em `new ExpirationPlugin({ maxEntries: 50, maxAgeSeconds: ... })`. Nenhuma outra rota /api ganhou cache.
Arquivos: `frontend/web/src/pwa/sw.ts`, `frontend/web/test/pwa-config.test.ts` (novo teste "expira por idade (7 dias)").
Testes: `pnpm --filter @pelada/web test -- src/pwa test/pwa-config` (o filtro foi ignorado e rodou a suíte do pacote: 1034 passando, 1 falhando). A falha é `os arquivos de ícone são os do mockup, byte a byte` (pré-existente, ícones de `public/icones` diferem do mockup; não tocados por esta tarefa). Rodando só `npx vitest run test/pwa-config`: 8 passam (inclui o novo), 1 falha (a mesma). `pnpm --filter @pelada/web build`: exit 0, dist/sw.js gerado.
Checklist de convenções: sem duplicação, sem ID de tarefa em código, comentário novo explica o porquê, arquivos pequenos. Lint/typecheck globais não rodados (fora do escopo, é do /testar).
Risco: a falha de ícones vs mockup precisa de tarefa própria (alheia a esta).

## 5. Resultado do QA
Veredito: APROVADA. Diff (bed428d0) confere: constante nomeada `RANKING_VALIDADE_SEGUNDOS = 7*24*60*60` usada em `ExpirationPlugin({ maxEntries: 50, maxAgeSeconds })`; nenhuma outra rota /api ganhou cache. Novo teste "expira por idade (7 dias)" passa. Executado `npx vitest run test/pwa-config`: 8 passam, 1 falha (ícones vs mockup). Convenções: sem duplicação, sem ID de tarefa em código, comentário explica o porquê, arquivo pequeno.
Falha preexistente confirmada: "os arquivos de ícone são os do mockup, byte a byte" falha por `public/icones` (última alteração no commit do TP-0108), não tocado pela RTP-0107. Aberta RTP-0116 (Lote-L23), sem reprovar esta tarefa.
Resumo para o relatório: APROVADA — maxAgeSeconds 7 dias no cache do ranking, teste novo passa; 0 críticos, 1 não crítico preexistente (ícones vs mockup) aberto como RTP-0116.
