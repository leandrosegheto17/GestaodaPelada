## 3. Plano de validação de segurança
- Autorização e isolamento na API (`exigirDono`, 404; ADR-005/G-03); a guarda do web não substitui. RF-07/ADR-005: a tela só desenha campos do `GrupoDono` strict e não tem atalho para dados internos (teste acima).
- Arquivar (RF-03, WCAG 3.3.4): a igualdade exata do nome é conferida na API (TP-0058); o diálogo só evita o clique acidental.
- Senha do D1 (ADR-004/ADR-015): só no resultado da mutação e na prop; `reset()` ao fechar; nada em armazenamento, URL, estado de navegação, log ou `console`.
- CSRF (G-09) via `escrever`; `id`/`contaId` com `encodeURIComponent`. G-18: link só da `urlPublica`. G-17: nenhuma resposta do dono no service worker. Texto da API sempre como texto.
